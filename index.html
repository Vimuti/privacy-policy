Privacy Policy for Modular Voice Toolbox

Effective Date: September 2026

1. Single Purpose & Data Minimization

Modular Voice Toolbox provides a customizable floating control panel for voice recognition and translation features. In compliance with Chrome Web Store Developer Program Policies, we only access and use data that is strictly necessary to fulfill this core function.

2. Data Collection and Usage

We do not collect, transmit, sell, or trade any personal data or web browsing history.

  • Voice Data: Speech input is processed locally by your browser's built-in Web Speech API to provide real-time recognition. Voice audio is never logged or saved.
  • User Settings: Your UI layout choices (orientation, scale ratio, and target languages) are stored exclusively on your device using chrome.storage.local.

3. Local Storage

All configuration data stays entirely within your local browser environment. No settings or user communications are ever sent to remote servers.

4. Third-Party Sharing

Modular Voice Toolbox does not share, monetize, or transfer any user data to third parties, advertising networks, or external entities.

5. Changes to This Policy

If practices change in future updates, this policy will be updated immediately. The effective date at the top will reflect the most recent revisions.

6. Contact Us

If you have any questions regarding this Privacy Policy or the Modular Voice Toolbox extension, please reach out through the official repository or email.
